# Kopi Senja — Java Coffee Ordering System

## About the Project
Kopi Senja is a Java console-based coffee ordering system developed for Object-Oriented Programming (OOP) Assignment 2.

This project demonstrates inheritance, polymorphism, encapsulation, interfaces, constructors, method overriding and method overloading.

## Features
- Coffee and non-coffee drink menu
- Drink size and temperature selection
- Membership discount (10%)
- Customer loyalty points
- Dine-in and takeaway options
- Add and remove ordered drinks
- Cash and E-Wallet payment
- Receipt generation
- Barista preparation instructions
- Input validation

## Java Classes
1. Drink.java — Parent class
2. CoffeeDrink.java — Coffee subclass
3. NonCoffeeDrink.java — Non-coffee subclass
4. DrinkPreparation.java — Interface
5. Customer.java — Customer information
6. Order.java — Order management
7. Payment.java — Payment processing
8. Receipt.java — Receipt generation
9. KopiSenjaMain.java — Main application

## How to Run
1. Download or clone the repository.
2. Open the project in a Java IDE.
3. Compile all Java files.
4. Run KopiSenjaMain.java.
